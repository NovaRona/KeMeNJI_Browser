# KeMeNJI Browser 🌌

A custom desktop browser built with Electron and Chromium.

KeMeNJI Browser is an experimental browser project focused on creating
a customizable browsing experience with a dark interface, tab management,
and future plans for an integrated web-based desktop environment.

## ✨ Features

- 🌐 Chromium-based web browsing
- 📑 Multiple tabs
- 🔎 Google search
- 🌙 Dark interface
- 🎨 Customizable wallpapers
- 🖥️ Experimental web-based OS integration
- ⚡ Desktop application built with Electron

> Note: Features may change as development continues.

## 🛠️ Built With

- Electron
- Chromium
- JavaScript
- HTML
- CSS
- Node.js
- npm

## 📋 Requirements

Before installing KeMeNJI Browser, make sure you have:

- Windows
- Node.js and npm
- An internet connection for dependency installation

Download Node.js from:
https://nodejs.org/
